# دفتر زبان — واژگان و نکته‌های انگلیسی

یک دفترچه‌ی شخصی، کاملاً ایستا و راست‌چین برای ثبت واژه‌های انگلیسی و نگهداری نکته‌های خام و اصلاح‌شده. رابط کاربری فارسی است و تمام اطلاعات در فضای ذخیره‌سازی مرورگر خودتان (`localStorage`) می‌ماند.

## امکانات

- افزودن واژه با یک یا چند معنی و نوع کلمه؛ نمایش و جست‌وجوی واژه‌ها در فهرست.
- مرور واژه‌ها با فلش‌کارت سه‌بعدی و دکمه‌های «قبلی» و «بعدی».
- ثبت هم‌زمان نکته‌ی خام انگلیسی و نسخه‌ی اصلاح‌شده، همراه با تاریخ و ساعت.
- دریافت فایل پشتیبان JSON و واردکردن فایل برای افزودن یا جایگزینی اطلاعات.
- چیدمان راست‌چین و واکنش‌گرا برای نمایشگرهای کوچک و بزرگ.

## اجرا

هیچ مرحله‌ی نصب یا ساختی لازم نیست. برای آزمایش سریع می‌توانید `index.html` را در مرورگر باز کنید. برای رفتار پایدارتر `localStorage` در اجرای محلی، فایل‌ها را از یک وب‌سرور ایستای ساده باز کنید؛ برای نمونه:

```sh
python -m http.server 8000
```

سپس نشانی `http://localhost:8000` را باز کنید. این سرور فقط فایل‌های ایستا را ارائه می‌کند؛ برنامه هیچ سرور برنامه‌ای، API، فریم‌ورک یا سرویس خارجی ندارد.

## استفاده از برنامه

1. در بخش «واژگان»، کلمه‌ی انگلیسی را بنویسید، نوع کلمه و معنی را انتخاب و وارد کنید. با «افزودن معنی دیگر» می‌توانید چند معنی برای یک واژه ثبت کنید.
2. واژه‌های ذخیره‌شده را در فهرست ببینید یا «حالت فلش‌کارت» را انتخاب کنید. با زدن روی کارت معنی‌ها آشکار می‌شوند؛ «قبلی» و «بعدی» میان واژه‌ها جابه‌جا می‌شوند.
3. در بخش «نکته‌ها»، متن خام انگلیسی را وارد کنید و متن اصلاح‌شده‌ای را که با کمک هوش مصنوعی آماده کرده‌اید در کادر دوم بچسبانید. برنامه هر دو متن را همراه با تاریخ و ساعت ذخیره می‌کند؛ اصلاح متن را خودتان در ابزار هوش مصنوعی انجام می‌دهید.
4. برای حذف واژه یا نکته از دکمه‌ی × کنار آن استفاده کنید.

## پشتیبان‌گیری، خروجی و ورود اطلاعات

- گزینه‌ی **«خروجی گرفتن (Export)»** یک فایل JSON با همه‌ی واژه‌ها و نکته‌ها دانلود می‌کند. این فایل را در جای امنی نگه دارید؛ داده‌های مرورگر به‌تنهایی نسخه‌ی پشتیبان نیستند.
- گزینه‌ی **«ورود اطلاعات (Import)»** یک فایل `.json` را می‌خواند. می‌توانید داده‌ها را به دفترچه‌ی فعلی اضافه کنید یا همه‌ی اطلاعات فعلی را با محتوای فایل جایگزین کنید. هنگام افزودن، معنی‌های تکراری برای یک واژه و نکته‌های تکراریِ همان زمان دوباره ثبت نمی‌شوند.
- برای ساخت واژه‌ها با کمک یک ابزار هوش مصنوعی، از آن بخواهید JSON مطابق نمونه‌ی زیر تولید کند، فایل را با پسوند `.json` ذخیره و سپس وارد برنامه کنید. کادر `notes` اختیاری است؛ برای فایل واژه‌ها می‌توانید آن را حذف کنید.

```json
{
  "version": 1,
  "vocabulary": [
    {
      "word": "curiosity",
      "meanings": [
        {
          "partOfSpeech": "noun",
          "definition": "کنجکاوی"
        },
        {
          "partOfSpeech": "noun",
          "definition": "a strong desire to know or learn something"
        }
      ]
    }
  ],
  "notes": [
    {
      "originalNote": "She go to school every day.",
      "improvedNote": "She goes to school every day.",
      "createdAt": "2026-11-20T12:30:00.000Z"
    }
  ]
}
```

هر واژه باید `word` متنی و `meanings` آرایه‌ای شامل دست‌کم یک مورد داشته باشد. هر معنی به `partOfSpeech` و `definition` متنی نیاز دارد. برای نکته‌ها، `originalNote` و `improvedNote` لازم هستند؛ `createdAt` زمان را با قالب ISO نگه می‌دارد و اگر برای نکته‌ی واردشده حذف شود، زمان ورود ثبت خواهد شد. برنامه همچنین فایل‌های خروجی خودش را می‌پذیرد؛ شناسه‌ها و فیلدهای اضافی مانند `exportedAt` اختیاری‌اند.

## انتشار در گیت‌هاب پیجز

گردش‌کار `.github/workflows/deploy.yml` پس از هر بار push به شاخه‌ی `main` فایل‌های ایستا را خودکار در GitHub Pages منتشر می‌کند. در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment** را روی **GitHub Actions** بگذارید. اجرای دستی گردش‌کار نیز از زبانه‌ی **Actions** ممکن است.

## نکته درباره‌ی نگهداری داده‌ها

داده‌ها فقط در `localStorage` مرورگر و دامنه‌ای که برنامه را از آن باز کرده‌اید ذخیره می‌شوند؛ میان دستگاه‌ها یا مرورگرها خودکار همگام‌سازی نمی‌شوند. پاک‌کردن داده‌های سایت یا مرورگر می‌تواند آن‌ها را حذف کند، پس خروجی JSON را به‌عنوان پشتیبان نگه دارید. برنامه هیچ داده‌ای را به اینترنت ارسال نمی‌کند.
