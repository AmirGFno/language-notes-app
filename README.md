# دفتر زبان — واژگان و نکته‌های انگلیسی

یک برنامه‌ی کاملاً ایستا و راست‌چین برای یادگیری واژه‌های انگلیسی، مرور با جعبه‌ی لایتنر و خواندن نکته‌های مشترک. برنامه با HTML، CSS و JavaScript ساده ساخته شده و backend یا API خارجی ندارد.

## امکانات

- نمایش واژه‌ها در خانه‌های مربعی؛ معنی پرکاربرد زیر واژه می‌آید و با انتخاب خانه همه‌ی معنی‌ها، مثال‌ها و توضیحات باز می‌شوند.
- تلفظ نوشتاری (IPA) و دکمه‌ی پخش با قابلیت گفتار داخلی مرورگر.
- جعبه‌ی لایتنر پنج‌مرحله‌ای با فاصله‌های مرور ۱، ۲، ۴، ۷ و ۱۴ روز.
- نکته‌های مشترک و فقط‌خواندنی که از فایل `shared-notes.js` مخزن بارگذاری می‌شوند.
- واژه‌ها و پیشرفت لایتنر هر کاربر جداگانه در `localStorage` همان مرورگر ذخیره می‌شوند.
- کاربران از فهرست نگهداری‌شده در مخزن انتخاب می‌شوند؛ ساخت حساب یا ثبت‌نام عمومی وجود ندارد.
- خروجی JSON برای پشتیبان‌گیری از واژه‌های پروفایل فعال. قابلیت ورود یا Import عمداً حذف شده است.

## اجرا

نیازی به نصب یا ساخت نیست. برای آزمایش محلی، از یک وب‌سرور ایستا استفاده کنید:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. سرور فقط فایل‌های ایستا را ارائه می‌کند؛ داده‌های شخصی در مرورگر می‌مانند.

## نکته‌های مشترک

فایل `shared-notes.js` بخشی از مخزن است و با سایت منتشر می‌شود. رابط برنامه برای همه‌ی بازدیدکنندگان فقط نسخه‌ی منتشرشده را نمایش می‌دهد و هیچ‌کس نمی‌تواند از داخل سایت نکته‌ای اضافه، ویرایش یا حذف کند. فقط نگهدارندگان مخزن می‌توانند محتوای این فایل را تغییر دهند؛ پس از ادغام تغییرات به `main`، گردش‌کار GitHub Pages سایت را منتشر می‌کند.

قالب هر نکته:

```js
window.REPOSITORY_NOTES = [
  {
    id: "note-1",
    originalNote: "She go to school every day.",
    improvedNote: "She goes to school every day.",
    createdAt: "2026-11-20T12:30:00.000Z"
  }
];
```

## کاربران و داده‌های محلی

فهرست کاربران در فایل عمومی `users.js` نگهداری می‌شود. هر کاربر باید یک `code` و نام فارسی (`nameFa`) داشته باشد؛ در فهرست فعلی، `AMIR` با نام نمایشی «امیر» تعریف شده است. فقط نگهدارندگان مخزن این فهرست را تغییر می‌دهند و رابط برنامه امکان ثبت‌نام یا ساخت کاربر ندارد.

واژه‌ها و وضعیت مرور لایتنر با کلید جداگانه‌ی هر کاربر در `localStorage` همان مرورگر ذخیره می‌شوند. داده‌های نسخه‌ی قبلی برنامه در مرورگر فعلی هنگام بازشدن به پروفایل `AMIR` منتقل می‌شوند. انتخاب کاربر فقط داده‌ی محلی همان مرورگر را عوض می‌کند.

کد کاربر شناسه‌ی عمومی است، نه رمز عبور یا توکن. انتخاب همان کد در دستگاهی دیگر، داده‌ها را منتقل یا همگام‌سازی نمی‌کند؛ هر کسی می‌تواند فایل‌های عمومی را ببیند. یک سایت ایستای GitHub Pages نمی‌تواند خودش فایل‌های مخزن را بنویسد. هیچ توکن محرمانه‌ای نباید در JavaScript عمومی سایت قرار گیرد.

## واژه‌ها و جعبه‌ی لایتنر

برای هر واژه می‌توان تلفظ، چند معنی، نوع کلمه، مثال و توضیح ثبت کرد. گزینه‌ی «معنی پرکاربردتر» مشخص می‌کند کدام معنی زیر خانه‌ی واژه نشان داده شود. واژه‌ی تازه همان روز در جعبه‌ی اول برای مرور آماده است. با «بلدم، بعدی» یک جعبه جلو می‌رود و با «هنوز یاد نگرفته‌ام» به جعبه‌ی اول برمی‌گردد.

نمونه‌ی یک واژه در خروجی JSON:

```json
{
  "word": "curiosity",
  "pronunciation": "/ˌkjʊr.iˈɑː.sə.t̬i/",
  "meanings": [
    {
      "partOfSpeech": "noun",
      "definition": "کنجکاوی",
      "example": "Her curiosity led her to ask more questions.",
      "explanation": "A strong desire to know or learn something.",
      "isPrimary": true
    }
  ],
  "leitnerBox": 1,
  "nextReviewAt": "2026-11-20T12:30:00.000Z"
}
```

## پشتیبان‌گیری

گزینه‌ی **«خروجی گرفتن (Export)»** واژه‌ها و وضعیت مرور لایتنر پروفایل فعال را به‌صورت JSON دانلود می‌کند. این فایل برای پشتیبان‌گیری است؛ Import از رابط برنامه حذف شده است. نکته‌های مشترک در فایل مخزن نگهداری می‌شوند و در خروجی شخصی قرار نمی‌گیرند.

## انتشار در GitHub Pages
