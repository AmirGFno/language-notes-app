# دفتر زبان — واژگان، نکته‌ها و اصطلاحات انگلیسی

یک برنامه‌ی ایستا و راست‌چین برای مطالعه‌ی واژه‌های انگلیسی، نکته‌های زبانی و اصطلاحات، همراه با مرور لایتنر. صفحه با HTML، CSS و JavaScript ساده ساخته شده و به backend یا API خارجی نیاز ندارد.

## امکانات

- واژه‌ها از `vocabulary.js` بارگذاری می‌شوند؛ همه‌ی بازدیدکنندگان فهرست یکسانی می‌بینند.
- هر واژه می‌تواند تلفظ، چند معنی، نوع کلمه، مثال و توضیح داشته باشد.
- جعبه‌ی لایتنر پنج‌مرحله‌ای با فاصله‌های مرور ۱، ۲، ۴، ۷ و ۱۴ روز.
- نکته‌های آموزشیِ بازنویسی‌شده از `shared-notes.js`، با توضیح فارسی و مثال‌های انگلیسی و ترجمه‌ی جداگانه.
- عنوان هر نکته در فهرست یک‌خطی است؛ با انتخاب آن، جزئیات در پنجره باز می‌شود.
- پنجره‌ی جزئیات نکته و واژه با کلیک روی فضای بیرون بسته می‌شود.
- اصطلاح‌های فقط‌خواندنی از `shared-idioms.js`.
- جست‌وجو در واژه‌ها و نمایش معنی‌ها و مثال‌ها.
- فونت‌های محلی فارسی و انگلیسی؛ برای نمایش فونت‌ها اتصال به سرویس بیرونی لازم نیست.
- هیچ کد کاربر، حساب، ثبت‌نام، ورود، Import یا Exportی وجود ندارد.

## محتوا و به‌روزرسانی

واژه‌ها، نکته‌ها و اصطلاحات در فایل‌های مخزن نگهداری می‌شوند و برای همه‌ی بازدیدکنندگان یکسان نمایش داده می‌شوند. صفحه فقط این محتوا را می‌خواند؛ برای افزودن یا ویرایش، تغییرها باید در فایل مربوط ثبت و منتشر شوند. GitHub Pages به‌تنهایی نمی‌تواند از داخل سایت در مخزن بنویسد.

- `vocabulary.js` — واژه‌ها و معنی‌ها
- `shared-notes.js` — نکته‌های آموزشی با بخش‌های فارسی و نمونه‌های انگلیسیِ جدا
- `shared-idioms.js` — اصطلاح، معنی، توضیح و مثال

نمونه‌ی یک واژه:

```js
{
  id: 'curiosity',
  word: 'curiosity',
  pronunciation: '/ˌkjʊr.iˈɑː.sə.t̬i/',
  meanings: [
    {
      partOfSpeech: 'noun',
      definition: 'کنجکاوی',
      example: 'Her curiosity led her to ask more questions.',
      explanation: 'A strong desire to know or learn something.',
      isPrimary: true
    }
  ]
}
```

نمونه‌ی یک نکته:

```js
{
  id: 'your-vs-yours',
  title: 'تفاوت صفت ملکی و ضمیر ملکی',
  intro: 'جایگاه دو ساختار ملکی در جمله با هم فرق دارد.',
  sections: [
    {
      title: 'صفت ملکی همراه اسم',
      text: 'پس از صفت ملکی باید اسم بیاید.',
      examples: [
        { english: 'This is your pen.', persian: 'این خودکارِ توست.', correct: true }
      ]
    }
  ],
  takeaway: 'صفت ملکی پیش از اسم می‌آید؛ ضمیر ملکی می‌تواند به‌تنهایی بیاید.'
}
```

هر جمله‌ی انگلیسی و ترجمه‌ی فارسی در فیلدهای جدا ذخیره می‌شوند تا رابط بتواند جهت چپ‌به‌راست و راست‌به‌چپ را مستقل و درست نمایش دهد. در توضیحاتی که فارسی و انگلیسی را در یک بند می‌آمیزند، متن را به بخش‌های جهت‌دار تقسیم کنید:

```js
explanation: [
  { lang: 'fa', text: 'در گفت‌وگو، ' },
  { lang: 'en', text: 'lend' },
  { lang: 'fa', text: ' هم کاربرد دارد.' }
]
```

نمونه‌ی یک اصطلاح:

```js
{
  id: 'break-the-ice',
  phrase: 'break the ice',
  meaning: 'سر صحبت را باز کردن؛ یخ جمع را شکستن',
  explanation: 'To make people feel more relaxed when they first meet.',
  example: 'He told a joke to break the ice.',
  register: 'محاوره‌ای' // اختیاری: برچسب لحن یا سطح رکاکت
}
```

## پیشرفت مرور

فهرست واژه‌ها، نکته‌ها و اصطلاحات برای همه یکسان است؛ پیشرفت جعبه‌ی لایتنر فقط در `localStorage` همان مرورگر ذخیره می‌شود. این پیشرفت به مخزن یا دستگاه دیگر منتقل نمی‌شود و حساب کاربری یا کد جداگانه‌ای وجود ندارد. واژه‌های محلی نسخه‌ی قدیمی در مخزن منتشر نمی‌شوند؛ برای ثبت واژه‌ای در فهرست مشترک، باید آن را در `vocabulary.js` اضافه کرد.

برای هر واژه می‌توان تلفظ، چند معنی، نوع کلمه، مثال و توضیح ثبت کرد. معنی پرکاربرد زیر خانه‌ی واژه دیده می‌شود. واژه‌ی تازه در جعبه‌ی اول برای مرور آماده است؛ با «بلدم، بعدی» یک جعبه جلو می‌رود و با «هنوز یاد نگرفته‌ام» به جعبه‌ی اول برمی‌گردد.

## فونت‌ها

فونت‌های Vazirmatn و Noto Sans Arabic برای فارسی و Inter و Roboto Flex برای انگلیسی در `assets/fonts/` قرار دارند. هر فونت مجوز SIL Open Font License 1.1 دارد و فایل مجوز کنار آن نگهداری می‌شود.

## اجرا و انتشار

نیازی به نصب یا ساخت نیست. برای آزمایش محلی:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. گردش‌کار `.github/workflows/deploy.yml` پس از ادغام تغییرها در `main` فایل‌های ایستا را در GitHub Pages منتشر می‌کند.
