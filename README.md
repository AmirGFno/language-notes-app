# دفتر زبان — واژگان، نکته‌ها و اصطلاحات انگلیسی

یک برنامه‌ی ایستا و راست‌چین برای مطالعه‌ی واژه‌های انگلیسی، نکته‌های زبانی و اصطلاحات عمومی، همراه با مرور لایتنر. صفحه با HTML، CSS و JavaScript ساده ساخته شده و به backend یا API خارجی نیاز ندارد.

## امکانات

- واژه‌های عمومی از `vocabulary.js` بارگذاری می‌شوند؛ همه‌ی بازدیدکنندگان فهرست یکسانی می‌بینند.
- هر واژه می‌تواند تلفظ، چند معنی، نوع کلمه، مثال و توضیح داشته باشد.
- جعبه‌ی لایتنر پنج‌مرحله‌ای با فاصله‌های مرور ۱، ۲، ۴، ۷ و ۱۴ روز.
- نکته‌های عمومی و فقط‌خواندنی از `shared-notes.js`.
- اصطلاح‌های عمومی و فقط‌خواندنی از `shared-idioms.js`.
- جست‌وجو در واژه‌ها و نمایش معنی‌ها و مثال‌ها.
- فونت‌های محلی فارسی و انگلیسی؛ برای نمایش فونت‌ها اتصال به سرویس بیرونی لازم نیست.
- هیچ کد کاربر، حساب، ثبت‌نام، ورود، Import یا Exportی وجود ندارد.

## محتوای عمومی و به‌روزرسانی

فهرست واژه‌ها، نکته‌ها و اصطلاحات بخشی از مخزن و عمومی است. بازدیدکننده‌ها این محتوا را فقط می‌خوانند؛ برای افزودن یا ویرایش، فهرست را به نگهدارنده‌ی برنامه می‌دهند تا تغییرها را در فایل مربوط ثبت و منتشر کند. GitHub Pages به‌تنهایی نمی‌تواند از داخل سایت در مخزن بنویسد.

- `vocabulary.js` — واژه‌ها و معنی‌ها
- `shared-notes.js` — نکته‌ی خام و نسخه‌ی اصلاح‌شده
- `shared-idioms.js` — اصطلاح، معنی، توضیح و مثال

نمونه‌ی یک واژه:

```js
{
  id: 'curiosity',
  word: 'curiosity',
  pronunciation: '/ˌkjʊr.iˈɑː.sə.t̬i/',
  meanings: [
    {
      partOfSpeech: 'noun',
      definition: 'کنجکاوی',
      example: 'Her curiosity led her to ask more questions.',
      explanation: 'A strong desire to know or learn something.',
      isPrimary: true
    }
  ]
}
```

نمونه‌ی یک نکته:

```js
{
  id: 'note-1',
  originalNote: 'She go to school every day.',
  improvedNote: 'She goes to school every day.',
  createdAt: '2026-11-20T12:30:00.000Z'
}
```

نمونه‌ی یک اصطلاح:

```js
{
  id: 'break-the-ice',
  phrase: 'break the ice',
  meaning: 'سر صحبت را باز کردن؛ یخ جمع را شکستن',
  explanation: 'To make people feel more relaxed when they first meet.',
  example: 'He told a joke to break the ice.'
}
```

## پیشرفت مرور

محتوای واژه‌ها و نکته‌ها و اصطلاحات عمومی و مشترک است؛ پیشرفت جعبه‌ی لایتنر فقط در `localStorage` همان مرورگر ذخیره می‌شود. این پیشرفت به مخزن یا دستگاه دیگر منتقل نمی‌شود و حساب کاربری یا کد جداگانه‌ای وجود ندارد. واژه‌های محلی نسخه‌ی قدیمی در مخزن منتشر نمی‌شوند؛ برای عمومی‌شدن، باید در فهرست `vocabulary.js` ثبت شوند.

برای هر واژه می‌توان تلفظ، چند معنی، نوع کلمه، مثال و توضیح ثبت کرد. معنی پرکاربرد زیر خانه‌ی واژه دیده می‌شود. واژه‌ی تازه در جعبه‌ی اول برای مرور آماده است؛ با «بلدم، بعدی» یک جعبه جلو می‌رود و با «هنوز یاد نگرفته‌ام» به جعبه‌ی اول برمی‌گردد.

## فونت‌ها

فونت‌های Vazirmatn و Noto Sans Arabic برای فارسی و Inter و Roboto Flex برای انگلیسی در `assets/fonts/` قرار دارند. هر فونت مجوز SIL Open Font License 1.1 دارد و فایل مجوز کنار آن نگهداری می‌شود.

## اجرا و انتشار

نیازی به نصب یا ساخت نیست. برای آزمایش محلی:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. گردش‌کار `.github/workflows/deploy.yml` پس از ادغام تغییرها در `main` فایل‌های ایستا را در GitHub Pages منتشر می‌کند.
